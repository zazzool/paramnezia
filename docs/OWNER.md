# Paramnezia для владельца семьи

С версии 2.20.0 семейные настройки входят в обычную Paramnezia. На смартфоне владельца откройте [последний релиз](https://github.com/zazzool/paramnezia/releases/latest), скачайте paramnezia.apk и подтвердите обновление поверх установленной версии. Сохраняйте данные приложения при обновлении.

## Первое подключение

1. На смартфоне владельца откройте раздел «Семья» и разверните «Резервные HTTPS-зеркала».
2. Нажмите «Использовать psync.ru», введите выданный владельцу токен записи и нажмите «Проверить и добавить». Для семьи требуется заранее настроенный адрес на psync.ru с правом записи. Приложение проверяет сохранение и чтение зашифрованных настроек.
3. Откройте Paramnezia на устройстве члена семьи, пока ему доступен один из текущих источников настроек. Устройство должно получить подписанный список зеркал до потери доступа к старому серверу. Токен нужен только владельцу.
4. Для обычной AmneziaVPN в том же разделе выберите семейный сервер с публичным IPv4. Галочка показывает выбор. В профиле AmneziaVPN один раз укажите awg-family.psync.ru и порт этого сервера.

## Смена адреса и замена сервера

При смене IPv4 у существующего сервера сохраните адрес в семейных настройках владельца. Paramnezia публикует новые настройки и передаёт IPv4 выбранного сервера зеркалу. Оставьте приложение открытым при временном сбое сети, чтобы оно повторило публикацию. В AmneziaVPN новое разрешение имени используется при переподключении.

При переезде на другой VPS сначала добавьте его в семью, дождитесь синхронизации на втором устройстве и проверьте подключение. Затем выберите новый сервер для AmneziaVPN. Даже при прежнем имени у него другой внутренний идентификатор. Если изменились порт, ключи или параметры AmneziaWG, проверьте регистрацию клиента и импортируйте соответствующий профиль в AmneziaVPN. Удаляйте старый сервер после проверки обоих клиентов.

## Проверка

- На устройстве члена семьи откройте список серверов и сверьте имя и адрес. Для проверки доступности нового сервера потребуется подключение к нему.
- В Windows команда `Resolve-DnsName awg-family.psync.ru -Type A -Server psync.ru` показывает опубликованный IPv4. Обычный DNS-резолвер может возвращать прежний адрес до истечения TTL.
