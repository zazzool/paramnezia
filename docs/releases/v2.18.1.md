# Paramnezia 2.18.1

- Android и Windows показывают новые серверы в списке подключения. Из списка можно перейти к управлению серверами, чтобы изменить настройки или удалить сервер.
- VPS, добавленный владельцем семьи, автоматически появляется у участников. Изменения названия, адреса и порта, а также удаление доставляются при синхронизации.
- Ранее добавленный локальный сервер с SSH-доступом можно включить в семью из его карточки.
