# Paramnezia 2.20.0 · Новый адрес для всей семьи

Семейная синхронизация через psync.ru вошла в основной выпуск для Android и Windows. Владелец обновляет адрес на своём устройстве, а близкие получают его при следующей синхронизации. Для этого один раз подключите зеркало и дайте семейным устройствам получить его адрес.

- Владелец семьи может публиковать подписанные настройки на HTTPS-зеркале psync.ru и выбирать семейный сервер для DNS-имени AmneziaVPN. Телефоны семьи должны хотя бы один раз получить список зеркал.
- При смене VPS сначала добавьте новый сервер, проверьте подключение и выберите его для DNS. Для обычной AmneziaVPN при смене ключа или порта потребуется обновить профиль.
- Для серверов из встроенного каталога приложение может сверять IP с данными хостера при включённом отслеживании адреса. Поддержаны IPv6-адреса при обнаружении устройств и проверке доступности сети.
- Android и Windows повторяют автоматическую проверку обновлений после сбоя. Подписанные манифесты обеих платформ содержат описание выпуска.
