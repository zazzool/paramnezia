## Paramnezia 2.6.0: клиент для Windows

**Новое: Paramnezia для Windows 10/11 (x64).** Те же экраны, ключи `vpn://`, приглашения, флот и серверы, что
на телефоне. Установщик: `Paramnezia-Setup-2.6.0.exe` ниже.

Установщик не подписан сертификатом разработчика, поэтому Windows при первом запуске покажет
«Система Windows защитила ваш компьютер». Нажмите **«Подробнее»**, затем **«Выполнить в любом случае»**.
Подробнее: [docs/WINDOWS.md](https://github.com/zazzool/paramnezia/blob/main/docs/WINDOWS.md).

Отличие от Android: Windows не умеет пускать отдельные программы мимо VPN, поэтому такой настройки там нет.

**Android:** изменений в поведении нет, общий код приложения теперь работает на обеих платформах.
