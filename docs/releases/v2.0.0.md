## Paramnezia 2.0.0

**Новая личность приложения.** Из-за предупреждений Google Play Protect о версиях 1.x всё, что связывало сборки с
ними, создано заново; осталось только название:

- пакет `net.paramnezia` вместо `io.paramnezia`, весь код в новом пространстве имён;
- новый сертификат подписи APK (SHA-256 `1C:19:A3:3B:D3:03:8E:59:41:F0:97:97:6D:C8:66:0E:5B:5A:89:4C:41:8F:8B:81:A7:35:C8:14:A5:0F:5F:20`);
- новый ключ релизов OTA (Ed25519) и новый Nostr-ключ публикации релизов.

**Как перейти с 1.x.** 2.0.0 — отдельное приложение, поверх 1.x не ставится и обновлением не приходит.

1. В старом приложении: «Настройки» → «Резервная копия» → «Сохранить ключи серверов» (если хотите сохранить
   серверы и флот; для полного обновления всех ключей этот шаг можно пропустить и развернуть сервер заново).
2. Удалите старую Paramnezia и установите 2.0.0.
3. Добавьте сервер из резервной копии или разверните заново; устройствам флота разошлите новые приглашения.

Если включена «Постоянная VPN» для старого приложения, выберите в настройках Android новое.
