## Paramnezia 2.1.0

**Проще и без признаков вредоносных программ.** Play Protect блокировал приложение по поведению кода, поэтому
из него убрано всё, что похоже на загрузчик или ботнет (подробно в `docs/PLAY-PROTECT.md`):

- обновления: приложение только сообщает о новой версии, APK скачивает браузер с `https://psync.ru/paramnezia/`
  по вашему нажатию, ставит Android. Разрешения на установку пакетов больше нет;
- Nostr и обмен между устройствами удалены. Устройства флота сами читают подписанную конфигурацию с сервера внутри
  туннеля и с HTTPS-зеркал; при блокировке сервера переходят на резервный и читают новую конфигурацию через него;
- проверка и починка серверов админом идёт, только когда приложение открыто.

Ставится поверх 2.0.0, настройки сохраняются.
