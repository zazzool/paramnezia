## Paramnezia 2.14.0

**Честная проверка адреса, новые иконки и мгновенные приглашения.**

- Исправлено: сразу после первого подключения «Зарубежные сайты» могли показывать Россию и ваш настоящий адрес,
  а после переподключения — страну сервера. Теперь проверка идёт только через туннель: пока он готовится,
  приложение пишет «проверяю…», а не чужую страну. Утечку через сеть оператора приложение распознаёт, даже
  если оператор выдаёт разные адреса, и тогда само перепроверяет соединение.
- Новые иконки во всём приложении: единый современный набор с аккуратными линиями. На главной кнопке, когда
  защита включена, значок питания плавно превращается в щит с галочкой.
- Добавить человека в семью теперь можно почти мгновенно: приложение заранее и незаметно готовит места на
  серверах. Файл настроек готов сразу, ссылка — за пару секунд.
- Приложение стало ещё немного меньше: лишний набор иконок больше не нужен.

То же самое в приложении для Windows.
