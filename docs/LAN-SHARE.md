# Раздача по Wi-Fi

С 2.12.0 любое устройство с Paramnezia раздаёт приложение (Android и Windows) устройствам в той же сети, а
администратор семьи (или владелец своего сервера) ещё и настройки. Внешний интернет для этого не нужен.

Главный сценарий — телевизор на Android TV / Google TV, где неудобно пользоваться браузером и набирать длинные
адреса, и компьютер с Windows, на который приложение ставится прямо с телефона.

## Как это выглядит

**На телефоне (или компьютере), который раздаёт:** «Семья» → «Раздать по Wi-Fi». Экран показывает короткий
адрес (`192.168.1.5:8080`, на Windows обычно просто `192.168.1.5`) и QR-код с ним. Раздача работает, пока этот
экран открыт (и не дольше часа).

**На телевизоре без Paramnezia:**

1. Открыть адрес в браузере телевизора. Если браузера нет — установить из Google Play бесплатное приложение
   «Downloader» (AFTVnews) и ввести адрес в нём. Цифры удобно набирать с телефона: приложение Google TV →
   пульт → клавиатура.
2. «Скачать Paramnezia» → «Установить» (Android один раз попросит разрешить установку из этого приложения).
3. Открыть Paramnezia: на главном экране сама появится кнопка «Получить настройки от <телефон>».
4. На телефоне — «Разрешить». Телевизор становится устройством семьи и подключается.

**На компьютере:** открыть адрес в браузере, скачать установщик. После установки Paramnezia так же сама найдёт
раздачу. Если Paramnezia уже стоит — кнопка «Получить настройки» есть и на странице в браузере (файл `.vpn` или
ключ).

**iPhone:** страница предлагает AmneziaVPN и выдаёт ключ после разрешения.

Если устройства не видят друг друга (гостевая Wi-Fi, «изоляция клиентов» на роутере), в «Добавить» есть
«По адресу раздачи»: адрес вводится вручную.

## Как устроено

```
client/src/main/kotlin/net/paramnezia/app/lan/
  LanProtocol.kt   типы и константы, интерфейс LanPlatform
  LanServer.kt     HTTP-сервер раздачи (только локальные клиенты)
  LanPage.kt       страница для браузеров (TV, Downloader, ПК, телефон)
  LanClient.kt     запрос настроек у соседа (сокеты, без HttpURLConnection)
  LanHub.kt        состояние для экранов: раздача, поиск соседей, кэш файлов
  LanNet.kt        локальные сети устройства (без VPN, мобильной сети и виртуальных адаптеров)
app/.../lan/AndroidLan.kt      NsdManager, установленный APK
desktop/.../DesktopLan.kt      JmDNS
app/.../ui/LanScreens.kt       «Раздать по Wi-Fi», «Получить настройки от…», «По адресу раздачи»
```

- **Обнаружение:** mDNS / DNS-SD, тип `_paramnezia._tcp` (так находят принтеры и Chromecast). Android — системный
  `NsdManager`, Windows — JmDNS на каждом адресе Wi-Fi/Ethernet.
- **Сервер:** порт 80 (адрес без порта), иначе 8080, 8888, 8000, 8008, 8081. Принимает соединения только из
  подсетей своих интерфейсов Wi-Fi/Ethernet/точки доступа (не через туннель).
- **HTTP:** `/` страница, `/a` APK, `/w` установщик Windows, `/info` JSON, `POST /join` запрос настроек,
  `/join/<id>` ответ (ожидание до 20 с), `/k/<id>` файл `.vpn` для браузера.
- **Настройки:** только после «Разрешить» на раздающем устройстве. Для семьи создаётся новое устройство семьи
  (`Links.forFleetDevice`, как «Пригласить» → «Файлом»), без семьи — отдельный ключ на своём сервере. Устройство
  видно в «Семья» → «Устройства», его можно отключить.
- **Файлы:** Android раздаёт свой установленный APK (тот же подписанный файл, что в релизе). Ничего не
  скачивается само: на экране раздачи у файла, которого нет (установщик Windows, APK на Windows) или который
  устарел, есть кнопка «Скачать» / «Обновить до X». По нажатию устройство читает подписанный `release.json` /
  `release-windows.json`, скачивает файл с GitHub Releases, сверяет размер и SHA-256 и хранит одну копию в кэше —
  в следующий раз интернет не нужен. Так телевизор, которому GitHub недоступен, получает последнюю версию через
  телефон. Приложение эти файлы не открывает и не запускает.
- **VPN включён:** локальные сети и mDNS идут мимо туннеля всегда (с 2.11.0), поэтому раздача и поиск работают и
  с включённым VPN.
- **Windows Firewall:** установщик добавляет правило «Paramnezia LAN» (входящие для Paramnezia.exe); без раздачи
  приложение ничего не слушает.

## Безопасность и Play Protect

- Раздача включается только вручную и видна на экране; закрыли экран — сервер остановлен и объявление снято.
- Сервер отвечает только соседям по локальной сети; настройки — только с разрешения владельца на экране,
  ключ для забора живёт 10 минут.
- Канал внутри Wi-Fi — обычный HTTP. Wi-Fi сам шифрует радиоканал (WPA2/WPA3); тот, кто уже в вашей сети, мог
  бы перехватить выданный ключ, поэтому раздавайте дома, а не в общественной сети.
- Это не обмен между устройствами в фоне (правило 10 в [PLAY-PROTECT.md](PLAY-PROTECT.md)): нет фоновых служб,
  ретрансляции и команд; сосед получает файл, только когда человек сам открыл адрес и нажал «Скачать».
- **Android 17 (targetSdk 37):** доступ к локальной сети станет разрешением. Пока targetSdk 36, оно не нужно.
  При переходе на 37 добавить `ACCESS_LOCAL_NETWORK` (запрос при открытии раздачи / поиска) или системный
  выбор устройства NSD.
