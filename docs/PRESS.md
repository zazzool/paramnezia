# Paramnezia · материалы для публикации

## Короткое описание

Paramnezia — семейный VPN на вашем сервере для Android и Windows. Владелец приглашает близких по ссылке и обновляет настройки подключения для всей семьи.

## Текст для анонса версии 2.20

Когда у VPN меняется адрес, обычно приходится вспоминать, у кого остался старый профиль. В Paramnezia 2.20 владелец сохраняет новый адрес один раз. Участники семьи получают его при синхронизации, даже если старый сервер уже недоступен, когда у них заранее настроено резервное зеркало.

Для подключения близкого человека достаточно одноразового приглашения. На Android и Windows доступны приложения Paramnezia, а на iPhone из приглашения можно импортировать профиль в AmneziaVPN. Для обычной AmneziaVPN предусмотрено постоянное DNS-имя. Замену ключей или порта нужно учесть в профиле отдельно.

## Частые вопросы

**Нужен ли каждому свой сервер?** Один VPS можно использовать для всей семьи. Сервером и приглашениями управляет владелец. У каждого приглашённого устройства свой доступ.

**Что нужно человеку, которого пригласили?** Открыть ссылку владельца, установить совместимое приложение и принять приглашение. Сервер арендует владелец.

**Как перейти с семейной сборки Android?** Официальный APK 2.20 устанавливается поверх 2.19.3-psync.2. Обе версии используют один пакет и один сертификат подписи.
