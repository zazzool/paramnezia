Почему это удобно

  • Ничего не надо выключатьБанки, Госуслуги, маркетплейсы и другие российские сервисы идут напрямую, как без VPN.
  • Работает, даже когда VPN блокируютТрафик замаскирован, а если сервер всё же заблокируют, приложение само перейдёт на запасной.
  • Меньше рекламы и слежкиРекламные и следящие адреса отсекаются ещё до загрузки страницы.
  • Не сажает батареюПока телефон спит, приложение почти не тратит заряд.

Если что-то не так

Телефон предупреждает при установке

Так Android встречает любые приложения не из Google Play. Нажмите «Подробнее» → «Всё равно установить». Если предложат отправить приложение на проверку, соглашайтесь.

Ссылка не открывает приложение

Сначала установите приложение (шаг 1), потом снова откройте ссылку. Если не помогло, на странице ссылки есть ключ: скопируйте его и вставьте в приложении на вкладке «Добавить».

Как обновлять приложение

Приложение само подскажет, когда выйдет новая версия. Обновление ставится поверх, настройки сохраняются.

Это безопасно?

Да. Приложение одно и то же для всех, его исходный код открыт. Ваш интернет идёт только через сервер того, кто вас пригласил.
