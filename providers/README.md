# Хостеры с API для «Купить сервер у хостера»

Список, по которому приложение покупает VPS одной кнопкой. Каждая строка проверена по **коду официального
SDK или CLI самого хостера** (не по статьям и не по сторонним обёрткам); ссылка на файл, по которому сверялись
адреса и поля, есть в таблице и в комментарии к классу провайдера в `deploy/src/main/kotlin/net/paramnezia/deploy/cloud/`.
Машиночитаемая копия: [`providers.json`](providers.json).

## Подключены (Cloudzy и Timeweb с 2.2.0; Vultr, Hetzner, DigitalOcean с 2.4.0)

| Хостер | API | Авторизация | Создание сервера | Источник, по которому сверено | Почему он |
|---|---|---|---|---|---|
| **Cloudzy** | `https://dash.cloudzy.com/api/v1` | `Authorization: Bearer <developer token>` (токен с ограниченными правами) | `POST /services` `{planId, region, hostname, billingCycle, osTemplateId, sshAuthorizedKeys[], config.userData}` + заголовок `Idempotency-Key`; цены `GET /pricing/catalog`; состояние `GET /services/{id}` (`state=active`, `ipAddress`) | [CloudzyVPS/cli `src/api/ops.rs`](https://github.com/CloudzyVPS/cli/blob/main/src/api/ops.rs), [`src/commands/catalog.rs`](https://github.com/CloudzyVPS/cli/blob/main/src/commands/catalog.rs) | основной сервер семьи уже у Cloudzy; принимает криптовалюту; много зарубежных локаций |
| **Timeweb Cloud** | `https://api.timeweb.cloud/api/v1` | `Authorization: Bearer <token>` | `POST /servers` `{name, preset_id, bandwidth, os_id, ssh_keys_ids[], cloud_init}`; тарифы `GET /presets/servers` (цена ₽/мес); ключи `GET/POST /ssh-keys`; состояние `GET /servers/{id}` (`status=on`, IPv4 в `networks[].ips[]`) | [timeweb-cloud/twc `twc/api/client.py`](https://github.com/timeweb-cloud/twc/blob/master/twc/api/client.py), [`twc/commands/server.py`](https://github.com/timeweb-cloud/twc/blob/master/twc/commands/server.py) | оплата российскими картами; локации в Нидерландах, Германии, Польше, Казахстане |
| **Vultr** | `https://api.vultr.com/v2` | `Authorization: Bearer <API key>`; в «Access Control» ключа разрешить все IPv4 | `POST /instances` `{region, plan, os_id, label, hostname, sshkey_id[], user_data(base64)}`; места `GET /regions`, тарифы `GET /plans` (`monthly_cost`, `locations`); состояние `GET /instances/{id}` (`status=active`, `power_status=running`, `main_ip`) | [vultr/govultr `instance.go`, `region.go`, `plans.go`, `os.go`, `ssh_key.go`](https://github.com/vultr/govultr), [vultr-cli `cmd/instance/instance.go`](https://github.com/vultr/vultr-cli/blob/master/cmd/instance/instance.go) (user_data в base64) | 30+ городов; нужна зарубежная карта или PayPal |
| **Hetzner Cloud** | `https://api.hetzner.cloud/v1` | `Authorization: Bearer <токен проекта, Read & Write>` | `POST /servers` `{name, server_type, image: ubuntu-24.04, location, ssh_keys[], user_data, labels}`; места `GET /locations`; тарифы и цены по месту `GET /server_types` (`prices[].price_monthly.gross`, только x86); состояние `GET /servers/{id}` (`status=running`, `public_net.ipv4.ip`) | [hetznercloud/hcloud-go `hcloud/schema/server.go`, `server_type.go`, `location.go`, `ssh_key.go`](https://github.com/hetznercloud/hcloud-go/tree/main/hcloud/schema) | дёшево, Германия и Финляндия; с декабря 2023 не работает с российскими адресами, нужен зарубежный аккаунт |
| **DigitalOcean** | `https://api.digitalocean.com/v2` | `Authorization: Bearer <personal access token>` | `POST /droplets` `{name, region, size, image: ubuntu-24-04-x64, ssh_keys[], user_data, tags}`; места `GET /regions`, тарифы `GET /sizes` (только `s-*`); ключи `/account/keys`; состояние `GET /droplets/{id}` (`status=active`, `networks.v4[type=public]`) | [digitalocean/godo `droplets.go`, `sizes.go`, `regions.go`, `keys.go`](https://github.com/digitalocean/godo) | сайт заблокирован РКН с апреля 2024 (API работает через VPN), нужна зарубежная карта |
